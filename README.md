# life-logging
我搭建的全天录音与信息处理系统（建筑在B站大佬@capsWriter开源方案之上），实现了对生活与工作流的全面数据化。为解决其处理10小时以上长音频的内存溢出问题，我通过动态分块机制对代码进行了关键性改造，确保系统能连续稳定运行。

具体流程如下：全天录音文件通过NAS自动同步至本地电脑，调用阿里开源的Paraformer模型进行识别，生成带有精细时间戳的SRT字幕文件。转录出的文本首先交由本地部署的Qwen3模型进行隐私脱敏处理，总结去除敏感细节后再传输至云端大模型进行校对纠错。

最终文本被自动分类为Obsidian笔记、发送至Flomo的灵感闪念、基于时间戳的柳比歇夫日程（大模型根据录音语境理解当前活动，并可配合特定语言标记提升准确性）、夜间自动检索的研究指令等。未来计划开发App持续记录空间位置与时间戳结合，形成可视化日程，通过轨迹变化辅助判断活动类型（如连续的快速位移推断为交通）。
